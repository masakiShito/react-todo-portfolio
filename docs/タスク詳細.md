# タスク詳細画面の設計

## 概要

このドキュメントでは、TODOアプリに追加したタスク詳細画面の設計と実装について説明します。

## 画面の目的

- タスクの詳細情報を一元的に表示・管理する
- タスクに対するコメントを追加・閲覧・削除する
- タスクの変更履歴をタイムライン形式で確認する
- タスクの編集画面への遷移を提供する

## 機能要件

### 1. タスク詳細表示

タスクの以下の情報を表示：

- タイトル
- 説明（description）
- ステータス（未着手 / 進行中 / 完了）
- 優先度（高 / 中 / 低）
- タグ（開発 / レビュー / MTG / その他）
- 期限（開始日 〜 終了日、またはいずれか一方）
- 作成日時
- 更新日時

### 2. コメント機能

#### 表示
- コメント一覧を新しい順で表示
- 各コメントには以下を表示：
  - 投稿者（現在は "me" で固定）
  - コメント本文
  - 投稿日時

#### 追加
- テキストエリアでコメント本文を入力
- バリデーション：
  - 空文字不可
  - 最大500文字
- 「コメント追加」ボタンで投稿

#### 削除
- 各コメントに「削除」ボタンを表示
- 確認ダイアログ後に削除

### 3. 履歴表示

タスクの変更履歴をタイムライン形式で表示（新しい順）：

- タスク作成
- タスク編集（title, description, priority, tag, endDate の変更）
- ステータス変更（完了/未完了の切り替え）
- コメント追加

各履歴エントリには以下を表示：
- 変更内容のメッセージ
- 変更日時

## データモデル

### Task型の拡張

既存のTask型に以下のフィールドを追加：

```typescript
type Task = {
  // ... 既存フィールド
  createdAt?: string;     // 作成日時（ISO文字列）
  updatedAt?: string;     // 更新日時（ISO文字列）
  comments?: Comment[];   // コメント配列
  history?: History[];    // 履歴配列
};
```

### Comment型

```typescript
type Comment = {
  id: string;             // UUID
  body: string;           // コメント本文
  author: string;         // 投稿者（"me"で固定）
  createdAt: string;      // 投稿日時（ISO文字列）
};
```

### History型

```typescript
type HistoryType = 'created' | 'updated' | 'status_changed' | 'comment_added';

type History = {
  id: string;             // UUID
  type: HistoryType;      // 履歴の種類
  message: string;        // 表示用メッセージ
  at: string;             // 変更日時（ISO文字列）
  diff?: {                // 変更差分（オプション）
    field: string;
    oldValue?: string;
    newValue?: string;
  };
};
```

## localStorage保存形式

### 後方互換性の確保

既存のタスクデータに `comments`、`history`、`createdAt`、`updatedAt` フィールドが存在しない場合でも正常に動作するよう、マイグレーション処理を実装：

```typescript
const normalizeTask = (raw: Partial<Task>): Task => {
  const now = new Date().toISOString();
  return {
    // ... 既存フィールド
    createdAt: raw.createdAt ?? now,
    updatedAt: raw.updatedAt ?? now,
    comments: Array.isArray(raw.comments) ? raw.comments : [],
    history: Array.isArray(raw.history) ? raw.history : [],
  };
};
```

### 保存タイミング

- タスク作成時：`createdAt` と `history` (作成履歴) を設定
- タスク更新時：差分を検出し `updatedAt` と `history` を更新
- コメント追加時：`comments` に追加し `updatedAt` と `history` を更新
- コメント削除時：`comments` から削除し `updatedAt` を更新

## UI/UXデザイン

### レイアウト

#### デスクトップ（lg以上）
- 2カラムレイアウト
  - 左（2/3）: タスク概要 + コメントセクション
  - 右（1/3）: 履歴タイムライン

#### モバイル
- 縦並びレイアウト
  1. タスク概要
  2. コメントセクション
  3. 履歴タイムライン

### デザイン方針

- 既存のダークテーマを継承
- ホバー・フォーカスの視覚フィードバックを提供
- モダンでシンプルなUI
- レスポンシブ対応

### 主要コンポーネント

- **TaskDetailPage**: メインコンポーネント（`/src/pages/TaskDetailPage.tsx`）
  - タスク詳細の表示
  - コメント機能（追加・表示・削除）
  - 履歴表示

## ルーティング

### パス設計

- `/` - ホーム（List / Board / Calendar ビュー）
- `/board` - ボードビュー
- `/calendar` - カレンダービュー
- `/tasks/:taskId` - タスク詳細ページ

### 遷移方法

各ビューからタスク詳細ページへの遷移：

1. **Listビュー**: 各タスクの「詳細」ボタンをクリック
2. **Boardビュー**: 各カードの「詳細」リンクをクリック
3. **Calendarビュー**: カレンダー上のタスクをクリック
