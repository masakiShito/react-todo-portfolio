# デザインガイド（2025-12-09更新）

## カラーパレット（現在）

- 背景: ネイビーブラック `#0F172A`
- アクセント: スカイブルー `#38BDF8`
- テキスト: ホワイトグレー `#F8FAFC`
- 補助（カード/フィールド）: 半透明ホワイト `bg-white/5`, 境界 `border-white/10`

意図:

- 落ち着いた背景で作業に集中できる環境
- アクセントは操作・選択の明確化（ボタン、タブ、チェック状態）
- 高コントラストで視認性を担保

## レイアウト

- 2カラム構成（モバイル: 1カラム）
  - 左: 新規タスク入力フォーム
  - 右: フィルタタブ + タスク一覧
- 最大幅: `max-w-5xl`
- 余白: ページ `px-6 py-10`、カード `p-6 sm:p-8`

## コンポーネント適用例

- フィルタタブ
  - アクティブ: `bg-[#38BDF8] text-[#0F172A]`
  - 非アクティブ: `bg-white/10 text-[#F8FAFC] border-white/10`
- TodoInput
  - フィールド: `bg-white/10 text-[#F8FAFC] border-white/10 focus:ring-[#38BDF8]`
  - 送信ボタン: `bg-[#38BDF8] text-[#0F172A]`
- TodoItem
  - チェック: `accent-[#38BDF8]`
  - 主要操作ボタン: `bg-[#38BDF8] text-[#0F172A]`
  - 副次操作ボタン: `bg-white/10 text-[#F8FAFC]`

## タイポグラフィ

- ベース: `text-[#F8FAFC]`
- 見出し: `font-semibold`、本文は読みやすさ優先で標準トラッキング
- 補助テキスト: `/#F8FAFC`の`/70~80`で階調管理

## アクセシビリティ

- フォーカスリングはアクセントカラーで明確化
- コントラスト比は高めに維持
- タブ/ボタンはキーボード操作前提

## 備考

- 近未来的な印象よりも落ち着きと清潔感を優先する配色
- 将来的にテーマ切替を導入する場合は`class`ベースのトグル対応を検討
