# デザインガイド（2025-12-09更新）

## カラーパレット（現在）

- 背景: ネイビーブラック `#0F172A`
- アクセント: スカイブルー `#38BDF8`
- テキスト: ホワイトグレー `#F8FAFC`

## 代替パレット（提案: チャコール × ネオン）

- 背景: チャコールブラック `#1E1E1E`（ダークテーマのベース）
- アクセント: ネオングリーン `#00FFB2`（近未来感・集中感アップ）
- テキスト: スモークグレー `#E5E7EB`（目に優しく見やすい）

採用時の変更点:

- ページ背景: `bg-[#1E1E1E]`、テキストベース: `text-[#E5E7EB]`
- カード/フィールド: `bg-white/5` と `border-white/10` のままでも可。緑の主張が強い場合は `border-white/8` に弱める
- フォーカス/強調: `ring-[#00FFB2]`、チェックボックス `accent-[#00FFB2]`
- プライマリボタン/アクティブタブ: `bg-[#00FFB2] text-[#1E1E1E]`
- セカンダリボタン: `bg-white/10 text-[#E5E7EB] hover:bg-white/15`

## レイアウト（不変）

- 2カラム（モバイル: 1カラム）、左: 入力、右: フィルタ + 一覧
- 最大幅 `max-w-5xl`、ページ余白 `px-6 py-10`、カード `p-6 sm:p-8`

## コンポーネント適用例

- フィルタタブ
  - アクティブ: `bg-[#00FFB2] text-[#1E1E1E]`
  - 非アクティブ: `bg-white/10 text-[#E5E7EB] border-white/10`
- TodoInput
  - フィールド: `bg-white/10 text-[#E5E7EB] border-white/10 focus:ring-[#00FFB2]`
  - 送信ボタン: `bg-[#00FFB2] text-[#1E1E1E]`
- TodoItem
  - チェック: `accent-[#00FFB2]`
  - 主要操作ボタン: `bg-[#00FFB2] text-[#1E1E1E]`
  - 副次操作ボタン: `bg-white/10 text-[#E5E7EB]`

## タイポグラフィ

- ベース: `text-[#E5E7EB]`、補助は `/70~80` の階調
- 見出し: `font-semibold`、本文は読みやすさ優先で標準トラッキング

## アクセシビリティ

- フォーカスリングはアクセント（ネオン）でも太さとコントラストを確保
- ネオンの彩度が強いため、ホバーは `opacity` 調整で眩しさ軽減

## 備考

- 近未来的な印象を重視する場合はネオン採用、落ち着き/清潔感重視なら現行（スカイブルー）を推奨
- 両パレットを切替可能にする場合はテーマトグルの導入を検討（`class`ベース）
