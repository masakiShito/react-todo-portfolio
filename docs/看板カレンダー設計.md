# Issue #16 看板・カレンダー機能 設計書

## 1) 目的・背景
- Issue #16「看板ボードやカレンダーでタスクを可視化する」を実現し、タスクを進捗・期限の観点で把握しやすくする。
- 既存のToDo一覧の体験を維持しつつ、Board/Calendarビューを追加する。

## 2) 画面構成と導線
- 画面構成
  - **List**: 既存のタスク一覧（フィルタ付き）
  - **Board**: 看板ボード（Todo / In Progress / Done）
  - **Calendar**: 期限付きタスクのカレンダー表示
- 導線
  - 画面右カラムのヘッダーに「List / Board / Calendar」のタブナビを追加。
  - ルーティングは `/`（List）・`/board`・`/calendar`。

## 3) データモデル（Task拡張・互換方針）
### Task拡張
```
status: "todo" | "in_progress" | "done"
dueDate?: string (ISO)
```

### 互換・マイグレーション方針
- 既存データ（配列形式）を読み込む際に `TaskStore` へ変換し、以下を補完。
  - `status` がない場合は `completed` を基に補完
    - `completed: true` → `status: "done"`
    - `completed: false` → `status: "todo"`
- `TaskStore` に `version` を持たせ、今後の変更に備えたバージョン付きの保存形式とする。
- 永続化キーは既存と同じ `todo-tasks` を利用。

## 4) UI仕様
### 看板（Kanban）
- カラム: `Todo / In Progress / Done`
- タスクカードをドラッグ&ドロップで移動可能
- 同一カラム内で並び替え可能（dnd-kitのsortable）
- ドロップ時に `status` を更新し `localStorage` に保存

### カレンダー
- `dueDate` があるタスクのみ表示
- 月/週/日 の切替に対応（最低条件のMonth含む）
- カレンダーのイベントをクリックすると編集モーダルを開く
- 期限未設定タスクはカレンダーに表示しない（画面上に案内文を表示）

## 5) コンポーネント設計
### 追加・更新コンポーネント
- `src/components/KanbanBoard.tsx`
  - dnd-kitでボードを実装
  - props: `tasks`, `onTasksChange`, `onEditRequest`
- `src/components/CalendarView.tsx`
  - react-big-calendarでカレンダー表示
  - props: `tasks`, `onEditRequest`
- `src/components/TaskEditModal.tsx`
  - List/Board/Calendar共通の編集モーダル
  - props: `task`, `tasks`, `onSave`, `onClose`

### 主要hooks/ユーティリティ
- `useLocalStorage` に `deserialize`/`serialize` オプションを追加
- `migrateTaskStore`（`src/utils/taskStorage.ts`）
  - 既存配列 → TaskStore へ変換
  - status/dueDate の正規化
- `dateTime` ユーティリティ（ISO ⇄ datetime-local変換）

## 6) 例外/エラーハンドリング方針
- 無効な `dueDate` はカレンダー表示から除外
- 期限の形式が不正・過去の場合はバリデーションでエラー表示
- マイグレーション時に不正値は安全側で補正
  - 不正な `status` → `todo`
  - 不正な `dueDate` → `undefined`

## 7) 手動テスト観点（例）
1. 既存データがある状態でリロードしてもタスクが消えない
2. 既存の `completed=true` タスクが `Done` カラムに表示される
3. Listでフィルタ（全件/未完了/完了）が動作する
4. Listで編集モーダルを開き、保存できる
5. Boardで同一カラム内の並び替えができる
6. Boardで別カラムへドラッグし、statusが更新される
7. Boardで移動したタスクがリロード後も維持される
8. Calendarに期限付きタスクが表示される
9. Calendarのイベントをクリックして編集できる
10. 期限未設定のタスクがカレンダーに表示されない
11. モバイル幅でボードが横スクロールできる
12. 期限を過去日に設定するとバリデーションエラーが出る

## 採用ライブラリと理由
- `@dnd-kit/core` + `@dnd-kit/sortable`
  - 軽量でReact向き、ドラッグ&ドロップの柔軟性が高い。
- `react-big-calendar` + `date-fns`
  - カレンダーUIを最小の実装負荷で提供でき、Month/Week/Day対応が容易。
- `react-router-dom`
  - List/Board/CalendarのURL遷移を明示し、共有可能な導線を維持。
