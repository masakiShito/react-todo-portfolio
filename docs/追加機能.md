# 追加機能アイデア

- 詳細ページを作成（タスクの個別ビュー、コメント/履歴表示）
- 表示順を期限優先に（期限→優先度→作成日でソート切替）
- 検索機能（タイトル/説明/タグで絞り込み）
- タグの複数選択・管理（作成/編集/削除）
- 繰り返しタスク（毎日/毎週/毎月、終了条件あり）
- 期限リマインダー通知（ブラウザ通知/PWA通知）
- 一括操作（まとめて完了/削除/タグ付け）
- 編集履歴と復元（変更ログ、元に戻す/やり直し）
- アーカイブ機能（完了済みを別リストへ退避）
- インライン編集の強化（Enter保存/ESCキャンセル/外側クリックで確定）
- i18n対応（日本語/英語切替）
- PWA化（オフライン・インストール対応、キャッシュ戦略）
- 共有/エクスポート（CSV/JSON、URL共有）
- カスタムビュー（看板ボード/カレンダー表示）
- アクセシビリティ改善（ショートカットキー、スクリーンリーダー最適化）
